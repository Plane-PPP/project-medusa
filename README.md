# Project Medusa

Оригинальная RPG на движке [OpenYAMM](https://github.com/pjasicek/openyamm). Главная героиня — полумедуза.

Состояние: организация проекта и аудит движка (фазы A–B). Игровых ресурсов пока нет.

| Каталог | Содержимое |
|---|---|
| `content/` | Пакеты для OpenYAMM в раскладке движка (`engine/rulesets/medusa/`) |
| `maps/` | Исходники карт: `.blend`, `.glb`, `geometry.yml`, `scene.yml`, Lua |
| `portraits/` | Исходники портретов высокого разрешения и экспорт |
| `scenes/`, `assets/` | Сцены и прочие собственные ресурсы |
| `scripts/` | Игровые скрипты и данные |
| `tools/` | Установка в движок, сборка карт и портретов |
| `docs/` | `TODO.md`, `DECISIONS.md`, `research/`, `design/` |

Начать: [CLAUDE.md](CLAUDE.md), [аудит](docs/research/medusa-engine-audit.md), [задачи](docs/TODO.md).

Лицензия контента не выбрана. Оригинальные ресурсы Might and Magic и Amber Island в репозиторий не входят.
