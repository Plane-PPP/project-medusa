# Портреты героини: техническая спецификация

Основание: [аудит](../research/medusa-engine-audit.md), раздел 4. Код — OpenYAMM `0c172ed`.

## Формат

- 56 кадров на лицо: `<префикс>01.png` … `<префикс>56.png`, 118×158 px, RGBA PNG, имена в нижнем регистре.
  Префикс Medusa: `med01-` (кадры `med01-01` … `med01-56`). Последние два символа имени должны быть цифрами: движок
  подменяет их номером кадра (`GameplayUiRuntime.cpp:265`).
- Портреты показываются в HUD (поверх рамки с дугами HP и маны), на экране создания партии, в инвентаре, в диалогах и
  на экране персонажа. Кадр должен читаться и в маленьком виде: крупное лицо, простой фон.
- После PNG — атлас `faces_med01.oytex` + `faces_med01.yml` (`tools/cook_ui_textures.py`). Где хранить PNG и атлас для
  ruleset-пакета, нужно проверить: сейчас лица лежат в `engine/icons_x2/`, а cooker удаляет «осиротевшие» атласы в
  этой папке.
- `DEAD` и `ERADCATE` — общие картинки для всех героев; свой кадр смерти движок сейчас не покажет.

## Приоритет состояний

`GameMechanics::displayedCondition` (`GameMechanics.cpp:3852`), от старшего к младшему:
Eradicated → Petrified → Dead → Unconscious (или HP ≤ 0) → Paralyzed → Asleep → Insane → Fear → Disease (любая
степень) → Poison (любая степень) → Weak → Cursed → Drunk. Больная и отравленная героиня показывается с кадром 09
(болезнь).

## Порядок работы

1. **Эталон (A).** Один кадр 01 в высоком разрешении (например 944×1264, ×8) → утверждение пользователем.
2. **Согласованность (B).** Из эталона: 01, 37–39 (урон), 08 (яд), 12 (окаменение), 11 (без сознания). Проверка
   положения головы, формы лица, числа и расположения змей, тона кожи и света. Кадры одной сетки: глаза на одной
   высоте, одинаковый масштаб головы.
3. **Полный набор (C).** Остальные кадры. Последовательности (25–29, 30–33, 34–36, 13–24) — это небольшие
   отклонения одного кадра: удобнее делать правкой эталона (inpaint), а не независимой генерацией.
4. **Интеграция (D).** Скрипт `tools/build_portraits.py` (план): исходники высокого разрешения в
   `portraits/med01/src/`, единое кадрирование по опорным точкам глаз, уменьшение до 118×158, проверка размеров и
   альфы, копирование в пакет, запуск `cook_ui_textures.py`.

Инструмента генерации изображений у Claude Code в этой сессии нет. Эталон делается во внешнем генераторе по
промптам из `heroine.md`. Старые портреты MM нельзя использовать как основу итоговой иллюстрации.
