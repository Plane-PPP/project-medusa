# Первая собственная карта: этаж башни

Подробности инструментов: [инструкция](../research/custom-indoor-level-workflow.md) и
[план прототипа](../research/tower-prototype-plan.md). Они собраны по коду и в этом checkout не выполнялись.

## Порядок

1. Временный старт: `out15.odm` из MM8 по ссылке (см. аудит, раздел 8).
2. Сборка `mm9_compile_indoor_source` и `openyamm_indoor_source_tests` в отдельном каталоге сборки
   `openyamm-medusa/build` через `safe-heavy-run` (решение пользователя: время и место на диске).
3. Итерация 1: две комнаты, проход, одна дверь, пол и потолок, простые текстуры, точка появления.
   Исходники в `project-medusa/maps/tower1/`: `tower1.glb` (из Blender или скрипта), `tower1.geometry.yml`,
   `tower1.scene.yml`, `tower1.lua`.
4. Регистрация: строка `map_stats` через append ruleset Medusa (id из диапазона Medusa), файлы карты — в
   `worlds/mm8/maps` через симлинк установщика или (позже) в собственном мире.
5. Старт на своей BLV требует исправления в движке (аудит, раздел 1).
6. Итерация 2: лестница, свет, сундук, NPC, событие, сохранение и загрузка.

## Конвейер (цель)

```text
maps/<id>/<id>.blend → <id>.glb → проверка geometry.yml → mm9_compile_indoor_source → <id>.blv
  → установка в пакет Medusa (tools/link-dev.sh) → headless-сценарий → запуск на машине пользователя
```

## Открытые вопросы

- Где монтировать BLV ruleset-пакета: в `maps/` монтируются только папки миров. Варианты — симлинк в
  `worlds/mm8/maps/` (неаккуратно) или свой мир (вариант B аудита).
- Текстуры: в v1 — существующие текстуры MM8 (локальная проверка), позже собственные.
