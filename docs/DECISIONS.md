## 2026-11-06 — Medusa как ruleset-пакет (предложено)

Почему: вкладки, сохранение id в savegame, замена и дополнение таблиц уже есть; правила остаются Standard; MAW
включается только для id `maw`. Новый мир потребовал бы правок жёстких списков `mm6/mm7/mm8` в нескольких местах.
Последствия: нужна небольшая правка `NewGameScreen` (карточка старта из `ruleset.yml`); Medusa и MAW нельзя
включить вместе; позже контент можно перенести в собственный мир. Подробно — аудит, раздел 7.

## 2026-11-06 — Временная стартовая карта `out15.odm` (предложено)

Почему: outdoor (обходит дефект indoor-старта), без NPC и сюжета, по ссылке без копии. Минусы: подводный режим,
неизвестные координаты старта.
