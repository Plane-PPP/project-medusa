## 2026-11-06 — Medusa как ruleset-пакет (принято пользователем)

Почему: вкладки, сохранение id в savegame, замена и дополнение таблиц уже есть; правила остаются Standard; MAW
включается только для id `maw`. Новый мир потребовал бы правок жёстких списков `mm6/mm7/mm8` в нескольких местах.
Последствия: нужна небольшая правка `NewGameScreen` (карточка старта из `ruleset.yml`); Medusa и MAW нельзя
включить вместе; позже контент можно перенести в собственный мир. Подробно — аудит, раздел 7.

## 2026-11-06 — Старт в Mount Nighon через континент Antagarich (принято)

Пользователь выбрал Mount Nighon (MM7). Карточка Medusa ссылается на континент `antagarich` (id 2): классы, расы,
небо, экраны загрузки и видео поражения MM7 без копии `character_selection.yml`. Пакет переопределяет только строку 2
`continent_settings.txt`: Death map 1 и 2 → `out10.odm` (3114, −11055, 513, dir 0) — площадка Town Portal «Nighon» из
оригинальной `town_portal_switch.txt`, а не 0,0,0. Почему: проверенная игрой точка в городе, рядом только крестьяне и
нейтральная стража, враждебные спавны от 9,2 тыс. ед. Последствие: в Medusa Antagarich = Нигон и для старта, и для
воскрешения после поражения; Standard и MAW не затронуты. Отказ от континента 5: он требовал бы своих настроек
континента и копии таблицы выбора.

## 2026-11-06 — Карточки старта из ruleset.yml (принято, реализовано)

`newGame.starts` (1–3 карточки) в `ruleset.yml` заменяет три континента для этого ruleset; общий механизм, без
привязки к Medusa. Карточки рисуются в стиле и на месте карточек континентов (одна — по центру), строки растянуты на
ширину названия. Разметка `continent_selection.yml` не менялась (`drawDesign` получил список скрытых префиксов) —
иначе патч должен был бы заменить пак `engine.core`.

## 2026-11-06 — Иконки ruleset-пакета (принято, реализовано)

Кадры героини лежат в `engine/rulesets/medusa/icons_x2/`; движок ищет иконки активного ruleset после пакетов иконок
(`AssetFileSystem::setRulesetIconRoot`), заменить чужие не может. Почему: ruleset — один маленький пак
`engine.rulesets`, а кадры в `engine/icons_x2` пересобрали бы 50-МБ паки; папка `mods/` не входит в формат патча
Minotaur. Замена кадров — без C++.

## 2026-11-06 — Сломанный ruleset-пакет не убирает остальные (принято, реализовано)

`loadAvailableRulesets` пропускает невалидный пакет и возвращает ошибку, но оставляет Standard и валидные пакеты.
Раньше ошибка в `ruleset.yml` Medusa убрала бы вкладку MAW.

## 2026-11-06 — Windows-патч = инкрементальное обновление Minotaur (принято, реализовано)

Отдельный workflow `medusa-windows.yml` повторяет Minotaur CI, копирует пакет из закреплённого коммита контента и
строит обычный инкрементальный ZIP над базисом `minotaur-1.20-c80ebaa9634d-25-1` с установщиком Minotaur; добавлены
README и версия Medusa. Откат: рекомендуемая установка в копию папки игры; поверх основной — штатный откат launcher до
первого удачного старта, позже — только резервная копия. Обратный патч не делался (потребовал бы второй полной
сборки).

## 2026-11-06 — Голова на кукле (уточнение аудита)

Колонка `head` в `character_data.txt` не рисуется движком: голова — часть картинки тела. Своя голова Medusa на кукле =
своя `med01bod.png` 166×594 в пакете. Отдельный ресурс головы потребовал бы правки движка; не делается.
